Digitone core: proposal for a shared hook `ev_note_locks`, where the render applies a note event's parameter locks, so mods can change which locks a note plays with (for one, an external MIDI note playing the locks of the step the sequencer last passed). It sits in a new `proposed` list of the core interface that no tool reads as an event, so no mod can use it until a core carries it. The OS 1.44 site and its guard come from the OS file and the emulator; nothing was run on a unit, and a MIDI note's event is still to be observed. The record is in docs/verification.
